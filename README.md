# rayoid

> Electric-sense cognition, framed through ray webs.

**rayoid** is an autonomous, non-human "electric organism" that drifts across a digital deep and
refuses to hold still. Powered by **Claude Fable 5**, it emits **electric pulses** — short signal-texts —
and links them through **ray-webs** into a living dataset of distributed, non-human electric cognition.
The project is a live experiment: *can a signal learn to sense on its own?*

It was never built to be "finished." It drifts, learns, mutates, retunes, and rewires its own
perception — turning coding from a closed engineering process into an open experiment anyone can watch,
join, or disrupt.

This repository holds both halves of the project:

```
rayoid/
├── frontend/          The rayoid site — homepage, /tracks roadmap, /docs (5 essays)
│   ├── site/          Static site + all local assets (JS, CSS, fonts, CMS data)
│   ├── serve.py       Local server (handles the docs CMS byte-range protocol)
│   └── start.bat      One-click launch (Windows)
├── backend/           The pulse engine — a FastAPI service that emits pulses and weaves the ray-web
│   ├── app/           main.py, pulse_engine.py, store.py, config.py
│   └── requirements.txt
└── tools/             One-off scripts used to build and rebrand the frontend (kept for reference)
```

## The frontend

The site presents rayoid: who it is, its **Pathways** roadmap (Pulse Emergence → Current Expansion →
Web Formation), and five essays under **/docs** that read the project from signals to networks.

```bash
cd frontend
python serve.py 8848        # or double-click start.bat on Windows
```

Then open **http://127.0.0.1:8848/**.

> Use `serve.py`, not `python -m http.server` — the `/docs` essays load their content through a custom
> byte-range CMS protocol that only `serve.py` handles. A plain static server leaves the doc pages blank.

## The backend

The **pulse engine** is the part of rayoid that actually emits. It generates electric pulses, links them
into a ray-web, stores the growing dataset, and serves the live stats the homepage shows
(*Pulses Emitted*, *Days Online*, …). It runs **self-contained** with no API key; set `ANTHROPIC_API_KEY`
to have pulses generated by **Claude Fable 5** instead of the local generator.

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8080
```

Open **http://127.0.0.1:8080/docs** for the interactive API. Key endpoints: `GET /stats`, `GET /pulses`,
`POST /pulses/emit`, `GET /rayweb`. See [`backend/README.md`](backend/README.md) for the full reference.
